## 🚀 Quick Start

### Method 1: Open Locally (Easiest)
```bash

2. Double-click portfolio.html to open in your browser
3. Click through the navigation menu
```

### Method 2: Deploy to GitHub Pages (Free Hosting)
```bash
1. Create GitHub account (if not already)
2. Create new public repository
3. Upload HTML files to repository
4. Enable GitHub Pages in Settings
5. Share the generated URL
```

### Method 3: Deploy to Netlify (Alternative)
```bash
1. Visit netlify.com
2. Sign up (free)
3. Drag and drop HTML files
4. Get instant URL
```

## 📝 Customization Guide

### 1. Change Colors
Find this in the `<style>` section:
```css
--primary-color: #0066ff; /* Change this */
--accent-color: #ff6b35;
```

### 2. Update Information
Replace all instances of:
- Madhav Sharma → Your name
- Phone number → Your number
- Email address → Your email
- LinkedIn URL → Your profile

### 3. Add Your Profile Picture
Replace placeholder image URL with your picture:
```html
<img src="your-photo.jpg" alt="Your Name">
```

### 4. Update Project Details
Modify project cards with:
- Your project titles
- Descriptions
- Technologies used
- Links to GitHub/demos

## 🐛 Troubleshooting

**Issue: Portfolio won't open**
- Solution: Try right-click → Open with → Browser

**Issue: Images not showing**
- Solution: Check file paths and internet connection

**Issue: Contact form not working**
- Solution: Verify email client is installed and configured

**Issue: Mobile layout broken**
- Solution: Clear browser cache (Ctrl+Shift+Delete)
